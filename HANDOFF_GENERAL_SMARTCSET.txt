1. QUÉ ES SMARTCSET
------------------------------------------------------------------------------

SmartCSET es un sistema de REGISTRO Y CONTROL DE PERSONAL para el SENA
(Servicio Nacional de Aprendizaje, Colombia). NO es "un sistema de portería":
tiene un componente de portería (control de acceso físico, ahora también vía
app móvil) MÁS un componente administrativo completo (usuarios, menús,
permisos, configuración visual, módulo standalone de registro de personas,
carga de reportes SENA DF-49/PE-04/juicios).

Stack: PHP 8+ puro (sin Composer, sin framework, sin autoloading PSR-4) +
PostgreSQL 14+ (lógica crítica de negocio en PL/pgSQL) + Bootstrap 5 +
vanilla JS. Desde 2026-06 también incluye una app móvil (Expo/React Native)
para tablets de portería + una API REST PHP que la sirve.

Desarrollador principal: Anderson (Anderson-029 en GitHub). Repo también
tiene colaborador KevinBermudezC (commits recientes de fixes/refactors en
porteria y login). Anderson está preparando el examen ISC2 Certified in
Cybersecurity (CC) y usa SmartCSET como proyecto práctico para cubrir el
temario (5 dominios: D1 Security Principles 26%, D2 BC/DR/IR 10%,
D3 Access Controls 22%, D4 Network Security 24%, D5 Security Operations 18%).

Ruta del proyecto: /home/ander/smartcset/ (este repo).
Repo remoto: github.com/KevinBermudezC/smartcset (rama main, al día con
origin/main según git status).
