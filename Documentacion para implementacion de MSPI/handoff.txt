  ## ⚠️ CONSIGNA PRINCIPAL: ESTÁNDAR DE CÓDIGO PEP8 (vigente desde 2026-06-13)

  A partir de esta sesión, **todo código Python** que se escriba para SmartCSET (scripts de utilidad,
  herramientas de diagnóstico, tooling auxiliar en `tools/`, etc.) debe cumplir **PEP8** estrictamente
  (línea ≤79 caracteres, nombres `snake_case`, imports ordenados, espaciado estándar) y pasar `ruff check`
  antes de commit, en línea con `backend_python.md` y `testing_quality.md` de las reglas globales.

  **Nota técnica:** SmartCSET es PHP 8+ puro (sin Composer/framework) — PEP8 no aplica directamente al
  grueso del código del proyecto. Para PHP, el estándar equivalente que se adopta como referencia de estilo
  es **PSR-12** (indentación 4 espacios, llaves en línea propia para clases/métodos, `camelCase` para
  métodos, `PascalCase` para clases — ya es el patrón seguido en `src/`). Esta consigna se aplica entonces así:
  - **Python** (cualquier script nuevo en `tools/`, `database/`, scripts de migración o diagnóstico): PEP8 + ruff.
  - **PHP** (todo `src/`): PSR-12 como referencia de estilo, manteniendo las convenciones ya documentadas en
    CLAUDE.md (nombrado de archivos/funciones, `require_once` relativo, prepared statements, etc.).
